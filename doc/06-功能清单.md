### 2026-09-28 实现增补（表内未逐行改写处以下列为准）

| 端侧 | 增补功能 | 说明 |
|---|---|---|
| Web | 服务台 / 统一工单 | 报修·投诉统一工单：派单、接单池、完工、评价；导航红点 |
| Web | 一线岗位人员 | 保安/保洁/绿化/机电；**不可登 Web**，任职后仅小程序 / App |
