## 1. 概念：去 MOCK

| 开关 | 环境变量 | 含义 |
|---|---|---|
| `app.wx.mock` | `WX_MOCK` | 登录 / 手机号 / 订阅消息：`true`=假数据；`false`=调微信 API |
| `app.wx.pay.mock` | `WX_PAY_MOCK` | 支付：`true`=MOCK prepay + 可调 notify；`false`=须配齐商户并接 JSAPI SDK |

本地开发默认二者均为 `true`。生产使用 `--spring.profiles.active=prod,mysql`（或等价），并显式传入环境变量。

## 8. 验收主路径（预发 / 生产前）

1. 平台登录 → 开小区 → 建物业经理并任职 → 强制改密  
2. 物业：空间/房型 → 导入或审核认证 → 住户栏任命业委会（须业主）  
3. 小程序真实登录 → 选身份 → 看房/账单  
4. 出账 → 线下确认收款（或正式支付）  
5. 统一工单：报修派单/接单/完工/评价；投诉闭环  
6. 公告（含 Banner 顺序）/ 投票各走一单  
7. 财务汇总口径：未缴不计收入；预缴 `prepaidIncome`；公开脚注  
8. **公共收益：** 按选定方案 A/B 走通并核对公开汇总  
9. 预缴协议方案 A：开启 → 签约 confirm → 出账跳过 → 作废/删除规则  
10. 费项九大类（Q34）：大类约束 + 垃圾费独立行  
11. 删小区：有住户须 `force`；审计 `ADMIN_DELETE_COMMUNITY`  
12. `subscribe_notify_log`：关 mock 后非全 SKIPPED
