# App 本地验收清单

编码范围已完成；下列用于真机 / H5 冒烟。支付不做。

## 前置

1. 后端：`cd server && mvn spring-boot:run`，确认 `GET http://127.0.0.1:8080/api/v1/health` 正常  
2. 管理端：物业登录 → 住户卡片「设App密码」（默认可空，系统用 `linliyuan123`）  
3. App：`cd app && npm run dev:h5`（或 HBuilderX 导入 `dist/build/app` 打 APK）  
4. 真机：登录页 API 改为电脑局域网 IP，如 `http://192.168.137.1:8080/api/v1`

## 打 APK

1. `npm run build:app-android`（已验证可产出 `dist/build/app`）  
2. HBuilderX 打开 `app/` → 发行 → 原生 App-云打包 → Android  
3. 安装后改 API 基址联调
